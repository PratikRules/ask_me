# AskMe - Multi-Modal Q&A Assistant

AskMe is a multi-modal Question & Answer assistant that can understand and respond to queries in various formats, including text, images, and audio. It leverages advanced AI techniques to provide comprehensive and informative answers.

## Features

- Support for various file uploads (PDF, DOCX, PPTX, TXT, CSV, XLSX, EPUB, common image and audio/video formats).
- Ability to process YouTube and general web URLs.
- Text extraction from documents.
- Audio transcription from audio and video files.
- Image understanding and question answering.
- Question answering on tabular data (CSV/XLSX) using PandasAI.
- Integration with multiple LLMs (Cohere, Gemini).
- Interactive chat interface using Streamlit.

## Technology Stack

- **Programming Language:** Python
- **User Interface:** Streamlit
- **Data Handling & Analysis:** Pandas, PandasAI
- **LLM Orchestration:** Langchain
- **LLMs:** Cohere, Google Generative AI (Gemini), Groq
- **Speech-to-Text:** AssemblyAI
- **File Processing:** Pypdf, python-docx, python-pptx, EbookLib
- **Image Processing:** Pillow
- **URL Processing:** youtube_transcript_api, pytube, beautifulsoup4
- **Vector Stores:** FAISS
- **Video Processing:** MoviePy

## Setup and Usage

Follow these steps to set up and run the AskMe project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/askme-project.git
    cd askme-project
    ```

2.  **Create and activate a virtual environment (recommended):**
    ```bash
    python -m venv venv
    # On Windows
    venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set up API Keys:**
    API keys are required for services like Google (Gemini), Cohere, AssemblyAI, and Groq.
    *   Create a `.env` file in the root directory of the project.
    *   Add your API keys to the `.env` file as follows:
        ```
        GOOGLE_API_KEY="YOUR_GOOGLE_API_KEY"
        COHERE_API_KEY="YOUR_COHERE_API_KEY"
        ASSEMBLYAI_API_KEY="YOUR_ASSEMBLYAI_API_KEY"
        GROQ_API_KEY="YOUR_GROQ_API_KEY"
        # PANDASAI_API_KEY="YOUR_PANDASAI_API_KEY" # Optional: Add if you plan to use PandasAI features extensively
        ```
    *   Obtain your API keys from the respective websites:
        *   Google AI Studio (for Gemini)
        *   Cohere
        *   AssemblyAI
        *   GroqCloud

5.  **Run the Streamlit application:**
    ```bash
    streamlit run askme.py
    ```
